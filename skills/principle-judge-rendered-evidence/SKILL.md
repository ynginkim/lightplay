# 렌더한 증거로 판정

**Why:** 장면 코드를 읽는 것으로는 화면이 어떻게 보이는지 알 수 없다. 만든 쪽은 의도를 화면에 투사해 약한 구간을 놓친다. 검사 스크립트는 문제를 표로 보여 주고도 정상 종료할 수 있다. Claude는 소리를 들을 수 없다.

**Pattern:** 품질 판정은 렌더한 스틸 시트, 프레임 띠, 장면 경계 프레임을 Read로 열어 보고 한다. 수정 전후는 같은 시각의 프레임으로 비교한다. 움직임·믹스·자동 검수 결과는 종료 코드가 아니라 표의 ✗·△와 "고칠 것"을 읽는다. 최종 렌더 전에 만든 맥락이 없는 비평을 한 번 받는다. 소리는 수치와 STT로만 확인했다고 밝히고 사람에게 청취를 요청한다.

**Stop:** 렌더러가 오류로 끝나 프레임이 없으면 먼저 오류를 고친다. 사람이 판정할 취향(음색, 리듬의 호불호)은 대신 판정하지 않고 요청 문장으로 넘긴다.
